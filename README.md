# Supplementary Material

This archive contains supplementary artefacts for the submitted paper.

## RoboSim Model and Forbidden Traces

- `SRanger.rst`: the adapted SRanger RoboSim model used in the paper.
- `SRanger_forbidden_traces.rtspec`: the complete specification containing
  the 42 forbidden traces used in the evaluation.

## Generated B Code

- `logic_i.imp`: generated B implementation containing the translated
  control logic.
- `user_ctx.mch`: generated B machine containing the model constants.
- `user_ctx_i.imp`: generated implementation of the model constants.

## LTL Formulas

- `formulas_SRanger.txt`: LTL formulae generated from the forbidden traces.
- `SRanger_scope10.tsv`: verification results for the baseline model at
  scope 10.
